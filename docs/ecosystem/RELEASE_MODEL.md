# Release model

## Estados

`draft → review → approved → implemented → tested → verified → released`

Os estados são distintos. `implemented` não equivale a `verified`; `documented` não equivale a `implemented`.

## Gate mínimo

Antes de release: links de origem, requisitos, critérios de aceite, target mapping, testes, evidência de validação, rollback e decisão de aprovação devem estar rastreáveis.

A existência de branches ou de artefatos de migração não representa release.
