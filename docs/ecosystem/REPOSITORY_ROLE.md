# Repository role

## É

Runtime, apps, packages, serviços, implementação de dados, infraestrutura, CI/CD, testes, observabilidade, deploy e release.

## Não é

Não é fonte de verdade documental para requisitos, evidências, decisões de negócio, contratos de produto ou governança.

## Contrato entre repositórios

- **Governance** controla autoridade, IDs, evidências, gates, riscos e decisões.
- **Blueprints** especifica produto, domínio, contratos, arquitetura e target mappings.
- **Maestro** provê agentes, skills, prompts, workflows e tooling operacional.
- **Ecosystem** implementa o HOW e registra evidência técnica sem promover especificação a release.

Nome-alvo: `sas-executar-ecosystem`. A renomeação permanece pendente de corte e atualização de links.
