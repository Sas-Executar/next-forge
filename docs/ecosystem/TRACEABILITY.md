# Traceability

Registrar, para cada mudança de implementação:

`source_repo → source_branch → source_commit → source_path → artifact_id → blueprint → requirement → acceptance_criteria → target → test → evidence → release`

Valores ausentes usam `GAP`; nunca devem ser inferidos como concluídos. Preservar hashes e caminhos de origem em cópias de proveniência.

## Design source

A matriz de reconciliação desta pasta referencia 120 arquivos de apps/packages do Desyng. Ela não substitui código, não declara equivalência e não autoriza sobrescrita.
