## 1. Dados que coletamos

Dados de conta (nome, e-mail, organização), dados de uso do produto (tarefas,
rotinas, integrações conectadas) e dados de pagamento processados pelo Stripe.

## 2. Como usamos os dados

Para operar o produto, dar suporte, prevenir fraude e melhorar a experiência.
Não vendemos dados pessoais a terceiros.

## 3. Compartilhamento

Compartilhamos dados apenas com provedores necessários para operar o serviço
(processamento de pagamento, autenticação, infraestrutura), sob contrato.

## 4. Seus direitos (LGPD)

Você pode solicitar exportação ou exclusão dos seus dados a qualquer momento
pelas configurações da conta.

## 5. Contato

Dúvidas sobre privacidade podem ser enviadas pelo canal de suporte do produto.
